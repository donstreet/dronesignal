# МОЙ ГОРОД — план реализации

Статус: старт разработки. Этот документ фиксирует требования; отметки реализации выставляются только после проверки кода и тестов.

## Основное приложение
- [ ] Переименовать UI в «МОЙ ГОРОД», сохранить тёмную тему с красными акцентами.
- [ ] Удалить все радио-панели, элементы навигации и воспроизведение радио.
- [ ] Главная: компактный рекламный баннер, SOS 112, «Я в опасности», Свет, Вода, Опасности, Новости, Онлайн-чат.
- [ ] Объявления администрации в отдельной ленте и релевантных разделах.
- [ ] Ограничить географию согласованной территорией; не добавлять выбор других городов.
- [ ] Запрос разрешения перед геолокацией и отправкой SMS; подтверждение экстренных действий.

## Административное приложение
- [ ] Авторизация с серверной проверкой роли admin.
- [ ] Создать объявление: заголовок, текст, категория (общее, свет, вода, новости, экстренное), изображение, ссылка/телефон, время публикации и окончания.
- [ ] Черновик, предварительный просмотр, публикация, редактирование, снятие с публикации.
- [ ] Опциональное push-уведомление по опубликованному объявлению.
- [ ] Журнал изменений: автор, время, действие; ограничение доступа к админ API на сервере.
- [ ] Управление модерацией чата и рассмотрение жалоб.

## Сервер / API (проектируемые контракты)
- GET /api/announcements — только опубликованные и актуальные объявления.
- POST /api/admin/announcements — создать черновик (admin).
- PATCH /api/admin/announcements/{id} — изменить (admin).
- POST /api/admin/announcements/{id}/publish — опубликовать (admin).
- POST /api/admin/announcements/{id}/unpublish — снять с публикации (admin).
- POST /api/admin/announcements/{id}/notify — push после публикации (admin, с защитой от повторной рассылки).
- Все операции записи требуют серверной аутентификации, валидации, лимитов размера и аудита.
- [ ] Реализовать миграции PostgreSQL и тесты доступа/жизненного цикла.

## Чат
- [ ] Сообщения в реальном времени.
- [ ] Автоматически скрывать мат, спам и запрещённый правилами контент; не подавлять обычные жалобы жителей.
- [ ] Предупреждения, временные ограничения, жалобы и ручной пересмотр решений.
