# МОЙ ГОРОД — новая версия

Новый Android-проект с чистого листа. Актуальные утверждённые требования: [SPECIFICATION.md](SPECIFICATION.md).

## Порядок разработки
1. Проверяем чистую сборку APK через GitHub Actions.
2. Экран выбора города ДНР и главный экран: тёмный дизайн, красные акценты, статус опасности.
3. Новости и объявления; свет и вода; подключение существующего API.
4. Оповещения, голос и push, проверка Telegram-checker.
5. Чат с подтверждением номера телефона, SOS с выбором действия, административные инструменты.
6. Тестирование и подписанная версия.

**Радио в новой версии отсутствует.** Старые архивы не используются как основа. Старую инфраструктуру не удаляем до проверки замены.

APK: `new-app/app/build/outputs/apk/debug/app-debug.apk`.
