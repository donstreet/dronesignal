# МОЙ ГОРОД — утверждённое ТЗ v1.0

Статус: пользователь утвердил перечисленные ниже требования. Отметка означает согласование, а не готовность реализации.

## 1. Главный экран
- Название «МОЙ ГОРОД»
- Тёмный дизайн, красные акценты, карточки в стиле Яндекса
- Текущий статус опасности сверху
- Переходы: Опасности, Свет, Вода, Новости, Чат
- SOS / экстренная помощь
- Карточка последнего важного объявления

## 2. Оповещения
- Telegram через серверный checker; раздельное распознавание ДНР/ЛНР
- БПЛА, ракетная опасность, массовая атака, отбой
- Фильтрация сообщений по городу
- Голосовое проговаривание тревоги и отбоя
- Push и звук; дедупликация
- Время, источник, актуальный статус
- Настройки звука и голоса
- Обработка отсутствия интернета и устаревших данных

## 3. Свет и вода
- Отдельные разделы
- Плановые/аварийные отключения; адреса и районы
- Ожидаемое восстановление, если известно; отметка восстановления
- Push о новых отключениях; история и актуальность

## 4. Новости и объявления
- Лента новостей; публикации администратора
- Фото и компактные миниатюры 9:16
- Заголовок, описание, дата, категория
- Внешняя ссылка и кнопка звонка
- Закреплённые важные сообщения
- Обновление контента без переустановки APK

## 5. Онлайн-чат
- Общий чат жителей; сообщения в реальном времени; имя пользователя
- Модерация нецензурной лексики; антиспам и защита от повторов
- Жалобы, администраторское удаление и блокировки; правила

## 6. SOS и безопасность
- Быстрый вызов 112; кнопка «Я в опасности»
- Подтверждение перед отправкой
- Геолокация только по разрешению
- SMS либо другой заранее настроенный способ SOS
- Работа при отказе в разрешениях
- Не обещать автоматическую связь с экстренными службами без реальной интеграции

## 7. Административная часть
- Защищённый вход
- CRUD объявлений; загрузка фото
- Категории: новости, свет, вода, экстренные сообщения
- Немедленная/отложенная публикация; push
- Модерация чата и жалоб; роли; журнал действий

## 8. Сервер и надёжность
- Существующие API и PostgreSQL
- Проверка Telegram-checker и контрольной точки
- Защита административных методов
- Очередь уведомлений без дубликатов
- Повторы при сетевых ошибках; состояние недоступности сервера
- Приватные логи; резервные копии БД

## 9. Android и выпуск
- Новый Kotlin / Jetpack Compose проект
- Название и иконка «МОЙ ГОРОД»
- Минимальные разрешения; фоновые уведомления
- Разные размеры экранов; перезапуск телефона
- GitHub Actions APK без Android Studio
- Установка и тест настоящего APK; подписанный релиз после проверки
- Полностью удалить радио из новой версии

## Дополнительно утверждено
- Приложение предназначено для городов ДНР, а не одного фиксированного города. Предусмотреть выбор города и привязку городских разделов и уведомлений к выбранному городу.
- Вход в чат по номеру телефона. Требуется подтверждение владения номером; не показывать номера другим участникам чата.
- Кнопка SOS открывает экран выбора экстренного действия, без автоматического вызова или отправки при одном нажатии.

## Ещё предстоит определить
- Перечень городов и источник справочника городов.
- Способ подтверждения телефона (например, SMS OTP) и его поставщик.
- Состав вариантов на экране SOS и их фактическая доступность.

## Правило реализации
Не считать пункт выполненным без проверки. Сначала чистая собираемая основа, затем функции с тестированием. Старый репозиторий/инфраструктуру не удалять до подтверждённой замены.
